Задание 1. Анализ расходов из CSV

Нужно реализовать Flask-приложение, которое помогает анализировать траты из банковской выписки.

Функционал:
1. Страница загрузки CSV-файла
    o HTML-форма, куда пользователь загружает CSV с данными о расходах
    o После успешной загрузки — редирект на вторую страницу

2. Страница анализа расходов
    o Отображает кнопки с вариантами анализа:
        – Общая сумма расходов по категориям (категория → сумма) / без за выбранный период
        – Группировка по дням / месяцам / годам (выбор периода в форме)

3. Обработка ошибок
    o Если файл некорректный (не CSV, нет нужных колонок и т. д.) — показывать страницу/сообщение с описанием ошибки

Требования:
• Python 3.7, Flask, pandas 1.3.5, requests
• Использовать разные типы запросов:
    o GET → страница загрузки файла
    o POST → загрузка CSV и переход на страницу анализа
    o POST → кнопки анализа на второй странице
