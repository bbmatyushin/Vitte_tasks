Задание 3. Асинхронные, синхронные и многопоточные запросы к API валют

Необходимо реализовать утилиту для получения валютных курсов, которая поддерживает синхронный, асинхронный и многопоточный режимы.

Функционал:
1.    Запуск из консоли
    o Bash-скрипт run.sh
        Параметры:
        --mode — sync, async, threads
        --metrics — CSV для сохранения времени выполнения
        --pairs-file — файл с валютными парами вместо ручного ввода

    Примеры запуска:
    ./run.sh --mode async
    ./run.sh --mode threads --pairs-file pairs.txt
    ./run.sh --mode async --metrics results.csv
    ./run.sh --mode threads --pairs-file pairs.txt --metrics results.csv

2.    Ввод валютных пар
    o Если --pairs-file не указан — ввод вручную через консоль
    o Ввод продолжается, пока пользователь не введёт две пустые строки подряд

    Пример:
    USD/RUB
    EUR/RUB
    GBP/USD


    --> ввод завершён

3.    Файл с валютными парами

    Формат: одна пара в строке
    USD/RUB
    EUR/RUB
    GBP/USD

4.    Получение курсов
    o Для каждой пары запрос к публичному API
    o Варианты:
        - sync
        - async
        - threads

5.    Вывод и метрики
    o На экран: список пар с курсами и время выполнения
    o При указании --metrics сохранять результат в CSV:
        - method,time_seconds
        - async,1.27сек

Требования:
• Поддержка ввода как вручную, так и через файл
• Тесты
• Документация пользователя и разработчика
