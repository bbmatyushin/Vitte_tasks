## Приложение анализа расходов
### Назначение проекта
Приложение предназначено для анализа личных расходов на основе загружаемых CSV-файлов.\
Основные функции:
* Загрузка CSV-файла
* Проверка структуры данных
* Анализ по категориям
* Анализ по времени (день/месяц/год)
* Отображение результатов в шаблонах
### Архитектура проекта
#### Основные модули
* **run.py** - запуск приложения
* **config.py** - основные настройки для приложения
* **app/static** - вся статика - css, js
* **app/templates** - html-шаблоны страниц
* **app/__init__.py** - функция для создания приложения и регистрации Blueprint
* **app/routes.py** - обработчики HTTP-запросов (Flask Blueprint)
  * загрузка файлов;
  * сбор данных для анализа;
  * отображение отчётов;
  * обработка ошибок.
* **app/utils.py** - вспомогательные классы:
  * `ValidatorCSV` — проверка файлов (структура, форматы);
  * `PreProcessor` — предобработка и анализ данных (группировка, агрегация).
* **tests/** - тесты
* **uploads/** - папка для хранения загруженных файлов
1. Модуль `routes.py`
   * `index()`
     * URL: `/`
     * Методы: `GET`
     * Назначение: возвращает страницу загрузки (`uploads.html`)
   * `upload_file()`
     * URL: `/upload`
     * Методы: `POST`
     * Назначение: загрузка и валидация CSV-файла:
       1. Проверка, что файл прикреплён.
       2. Сохранение имени файла в `session["filename"]`.
       3. Проверка:
          * файл существует и не пустой;
          * расширение допустимо (только `.csv`);
          * заголовки и формат данных корректны.
       4. При успешной загрузке → редирект на `/analyze`
   * `analyze()`
     * URL: `/analyze`
     * Методы: `GET`, `POST`
     * Назначение: анализ расходов.
     * Логика:
       1. Загрузка CSV из `session["filename"]`
       2. Обработка с помощью `PreProcessor.process_df()`
       3. Определение доступных годов и месяцев
       4. Варианты анализа:
          * по категориям (`category_analysis`);
          * по периодам (`dates_analysis`);
          * по временным интервалам (дни, месяцы, годы).
       5. Возврат результата в шаблон `analyze.html`
   * `clear_cache()`
     * URL: `/clear-cache`
     * Метод: `POST`
     * Назначение: принудительно очищает весь кеш
   * `status()`
     * URL: `/status`
     * Метод: `GET`
     * Назначение: выводит пользователю некоторую информацию о сервере
2. Модуль **[utils/validator_csv.py](app%2Futils%2Fvalidator_csv.py)**\
Класс `ValidatorCSV`- отвечает за проверку CSV-файлов.
   * `allowed_file(filename)` — проверяет расширение.
   * `csv_columns_validate(df)`:
     * наличие обязательных колонок: `date`, `category`, `amount`;
     * корректность формата даты;
     * корректность суммы (`float`).
3. Модуль **[utils/pre_processor.py](app%2Futils%2Fpre_processor.py)**\
    Класс `PreProcessor`- предварительная обработка и анализ данных.
   * `process_df(df)`:
     * конвертация типов (date → datetime, amount → float);
     * извлечение года, месяца, текстового названия месяца;
     * сортировка по дате.
   * `get_months_years(df)` — возвращает уникальные месяцы и годы.
   * `category_analysis(df)` — анализ по категориям (сумма расходов).
   * `dates_analysis(df, date_type, selected_years, selected_months)` — анализ по выбранному периоду:
     * `year` - группировка по годам;
     * `month` - группировка по месяцам;
     * `month_year` - группировка по комбинации (год + месяц).
4. Модуль **[utils/cache.py](app%2Futils%2Fcache.py)**\
   Класс `Cache` - класс для кэширования результата анализа для созлания параметризованный декоратор с TTL. Создан с использованием паттерна Singleton.
    * `set_ttl(ttl)` - установить время жизни кеша в секундах
    * `get_key(filename, user)` - Сформировать ключ по имени файла и имени пользователя
    * `is_expired(timestamp)` - Проверить, истекло ли время действия кеша
    * `set(filename, user, result)` - Сохранить результат в кеш
    * `get(filename, user)` - Вернуть значение из кеша или None, если кеша нет или просрочен
    * `clear()` - Очистить весь кеш
    * `stats()` - Статистика: размер кеша и ключи (используется на `/status`)
    * `cached(ttl)` - Декоратор для кеширования функции
#### Внешние зависимости
* Python 3.7
* Flask — веб-фреймворк;
* pandas — работа с CSV и аналитика;
* pytest – для тестирования
### Запуск приложения
1. Создать виртуальное окружение
```bash
python3 -m venv .venv  
```
2. Установить зависимости
```bash
source .venv/bin/activate
pip install -r requirements.txt
```
3. Запустить приложение
```bash
python run.py
```
